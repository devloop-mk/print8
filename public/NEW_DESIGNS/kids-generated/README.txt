print8.mk — Kids tee spot designs (generated)
==============================================
Folder: public/NEW_DESIGNS/kids-generated/

Style: kawaii/cute cartoon animals, bold clean outlines, soft vibrant colors,
party hats + birthday props, centered chest-print spot illustrations.
Family-friendly originals (no trademarked characters).

Format: PNG with alpha (white background keyed out via sharp).
Target size: ~2400px on the long side after trim + upscale.
Use: DTG / screen print chest graphics — not shirt mockups.

Notes
-----
- Backgrounds are true transparent PNGs (alpha channel). White backgrounds were
  removed with edge flood-fill (preserves interior white/cream fur better than
  a global color key). A thin soft fringe may remain at edges — spot-check
  before production print, especially panda/unicorn/bunny.
- Not added to the product catalog / DB — design assets only.
- Source generations live under the Cursor project assets folder; this folder
  holds the processed print-ready exports.
- Re-run processing: node scripts/process-kids-tee-pngs.mjs
